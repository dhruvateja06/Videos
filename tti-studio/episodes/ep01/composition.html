The everyday mystery

to ask.

  • It's not a fixed timer.Order an hour later — it might say 41.

  • So something else is guessing.Something new. That's our subject today.
Attempt #1 — write the rules

If you were the developer,
you'd start the obvious way.

if restaurant_is_busy → wait += 5
if raining → wait += 7
if driver_distance >2km → wait += 4
if weekend → wait += 3
For the first twenty orders, it works great.
Why writing rules collapses

Then reality walks in and slaps your program.

  • The combinations explode.Weekend × rain × traffic × driver load × restaurant speed = millions of cases.
  • Every fix breaks something else.Patch one situation, three new ones appear.
  • Reality keeps changing.New areas, festivals, road closures — faster than you can write rules.
No human can write all the rules. Reality is too messy.
The big shift

So engineers flipped the problem upside down.

Old way — traditional software
New way — AI
A human writes the rules
The computer discovers the rules
You tell it what to do
You show it what already happened
Breaks on situations you forgot
Improves as it sees more examples
Like a child learning "dog" — not from a rulebook, but from seeing enough dogs.

Step 2 · Pattern

"Finding the pattern" — literally drawing a line through the data.

  • Plot every orderdistance across, time up.
  • The trend is right therefarther usually means longer.
  • The computer draws the linethat best fits all the dots.
That line is the pattern. We call it a model.
Step 3 · Predict

A new order? Just read the answer off the line.

No rule was written. The model just read your answer off the line.
The definition

AI is software that
learns the pattern from examples,
instead of being told the rules.

LEARNS
It improves on its own.
PATTERN FROM EXAMPLES
It studied millions of past cases.
NOT TOLD THE RULES
No human wrote the logic.
Side by side

Normal software vs AI software.

Normal software — a calculator
2 + 2 = 4, always.
Rigid. Exact. Never changes. Great for fixed logic.
AI software
Gets better with more data.
Messy. Flexible. Improves. Great for real-world problems.
Neither is "better" — different tools for different jobs.
The mental model

Two words to carry through the whole series.

RULES vs PATTERNS
  • Old software runs on rules — written by a human.
  • AI runs on patterns — learned from data.
  • Hear "AI" anywhere? Think pattern, not rule.
