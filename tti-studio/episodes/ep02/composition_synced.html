two questions, one app (Swiggy)

Tonight answers two questions.

the one analogy for tonight

Every app is a restaurant.

the client · the frontend

Your phone is the dining room.

the server · the backend

The kitchen runs the show.

where does the data live?

The database is always server-side.

Your phone is a window onto the data — not where it's kept.
the golden rule of system design

Never trust the client.

Anyone can edit their own device. The server has the final say — every time.
the api · the waiter

One kitchen. Many dining rooms.

Split it for security (rules in one place), reuse (many apps, one backend) and scale.
who draws the screen?

Speed to first view: SSR vs CSR.

Most big apps do both. A trade-off, not a winner.
now: how does your phone find swiggy?

Billions of computers. You know one name.

A name is easy to remember. The network only moves data to numbers.
every server has a number

Meet the IP address.

It's the server's phone number. (This is IPv4; newer IPv6 ones are far longer.)
names in, numbers out

DNS is the internet's phonebook.

You remember the name. DNS remembers the number.
// the dns lookup

Finding the number is a relay race.

Root & TLD don't know the address — they just say "ask them next."
look it up once, remember it

The second visit is instant.

A myth to drop: DNS only finds the address. It never loads the page itself.
now they can talk

HTTP is the shared language.

One ask, one answer — then it forgets you. (That matters in a minute.)
anatomy of a request

What's actually in a request?

two everyday verbs

GET reads. POST writes.

⚠ Send a POST twice → two orders. (We fix that in a later episode.)
how it remembers you (HTTP forgets!)

The cookie is your ID badge.

Headers are labels on every request. The login cookie says "it's me again."
how it went

Every answer comes with a code.

Easy rule: 4-something = your fault, 5-something = the server's.
the s is for secure

HTTP is a postcard. HTTPS is a sealed envelope.

The padlock means encrypted, not "trustworthy." Scam sites can have one too.
the whole journey, end to end

One tap on Swiggy. Here's everything.

Find the address, knock in the right language, get your answer back. That's the web.
